# TODO List на C++

Консольное приложение для управления списком задач.  
Позволяет добавлять, удалять, редактировать и просматривать задачи.  
Все данные сохраняются в файл `todo.txt` и загружаются при следующем запуске.

## Требования

- Компилятор C++ с поддержкой C++17 (g++ или clang++)
- Linux (или WSL, или MinGW для Windows)
- Терминал

## Сборка и запуск

Если весь код находится в `main.cpp`:

```bash
g++ main.cpp -o todo
./todo
```
